# M0 — Project foundation

## Goal

Establish a buildable, testable foundation for RexxTelnet before introducing
AmigaOS-specific runtime complexity.

## Product definition

RexxTelnet is a lightweight Telnet client for classic AmigaOS whose automation
interface is a first-class feature.

It is not intended to become an SSH client, web browser, or general-purpose
communications suite.

## Compatibility contract

The production client targets:

- AmigaOS 2.04+
- 68000+
- no FPU requirement
- TCP/IP through bsdsocket.library-compatible stacks
- Bebbo GCC-compatible C implementation
- ARexx when rexxsyslib.library / RexxMast are available

The core should avoid unnecessary post-C89 dependencies to keep the 68k build
portable.

## Architecture

The codebase is split into independently testable layers:

1. **telnet core** — byte-stream Telnet parser and encoder;
2. **transport** — bsdsocket.library connection and I/O;
3. **terminal** — display/input, ANSI/VT behavior and scrollback;
4. **session** — state, capture, buffering and WAITFOR matching;
5. **ARexx** — command parsing and RexxMsg lifecycle;
6. **application** — startup, CLI/ToolTypes and event loop.

The Telnet core must stay free of AmigaOS dependencies.

## Initial Telnet scope

Required for the early implementation:

- RFC 854 framing
- IAC escaping
- DO / DONT / WILL / WONT
- BINARY
- ECHO
- SUPPRESS-GO-AHEAD
- subnegotiation framing
- NAWS after terminal dimensions exist

Unknown options must receive safe negative negotiation rather than being
silently accepted.

## ARexx contract

Port name:

```
REXXTELNET
```

Initial command vocabulary:

- `CONNECT host [port]`
- `DISCONNECT`
- `SEND text`
- `SENDLINE text`
- `SENDHEX bytes`
- `WAITFOR text [timeout]`
- `READ`
- `PEEK`
- `STATUS`
- `CAPTURE file`
- `CAPTURE STOP`
- `GET property`
- `SET property value`
- `QUIT`

The command syntax is part of the public interface. Additive extension is
preferred over incompatible changes.

## M0 acceptance criteria

- repository has an explicit target/compatibility contract;
- source layout separates protocol core from AmigaOS platform code;
- Telnet parser handles plain data, escaped IAC, option negotiation and
  subnegotiation framing;
- host tests build with strict warnings and pass;
- ARexx port name and initial command vocabulary are documented;
- milestone roadmap exists;
- MIT license is present.

## Out of scope for M0

- opening bsdsocket.library
- actual TCP connections
- Intuition terminal window
- console/ANSI rendering
- creating an ARexx public port
- WAITFOR implementation
- Amiga native/runtime qualification

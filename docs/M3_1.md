# M3.1 — ARexx dispatch and replies

M3.1 turns the public `REXXTELNET` port into a functional command endpoint.

Implemented:

- `RexxMsg` receive/reply loop on AmigaOS
- command dispatch through a host-testable callback interface
- stable `RC` values: 0 OK, 5 state warning, 10 syntax/command/execution error
- `RESULT` strings when requested by the caller
- commands: `STATUS`, `CONNECT`, `DISCONNECT`, `SEND`, `SENDLINE`, `GET`, `SET`, `QUIT`
- `GET COLUMNS|ROWS`
- `SET COLUMNS|ROWS value`
- ARexx polling integrated into the interactive Amiga runtime
- remote disconnect no longer terminates the application; ARexx may reconnect it
- host tests for dispatch behavior

Example:

```rexx
ADDRESS REXXTELNET
'STATUS'
SAY RESULT
'SENDLINE hello world'
'GET COLUMNS'
SAY RESULT
```

Native Amiga compilation and live RexxMast runtime qualification remain pending.

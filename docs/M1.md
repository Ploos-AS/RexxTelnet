# M1 — TCP session core

## Delivered

M1 introduces the first networking/session layer while keeping protocol logic host-testable.

- portable transport API
- POSIX TCP implementation for development and later integration tests
- Amiga transport implementation using `bsdsocket.library`
- DNS/IPv4 connect path
- send/receive/disconnect primitives
- Telnet negotiation policy
- outbound IAC escaping
- host tests for negotiation and encoding

## Negotiation policy

Initially accepted remote options:

- BINARY
- ECHO
- SUPPRESS-GO-AHEAD

Initially accepted local options:

- BINARY
- SUPPRESS-GO-AHEAD

Unknown remote `WILL` options are answered with `DONT`; unknown remote `DO` options are answered with `WONT`.

NAWS remains deferred until the terminal layer supplies real dimensions.

## Amiga transport

The Amiga backend opens `bsdsocket.library` version 4 or newer on demand, resolves an IPv4 hostname with `gethostbyname()`, creates a TCP socket, and exposes connect/send/receive/disconnect through the same transport interface used by the rest of the program.

Native compilation and runtime qualification are deliberately deferred to the qualification milestones; host CI validates the portable core continuously.

## M1 acceptance

- M0 parser remains intact
- negotiation policy is deterministic and tested
- unknown Telnet options are rejected safely
- outbound IAC bytes are escaped
- TCP transport contract exists
- POSIX implementation exists
- Amiga `bsdsocket.library` implementation exists
- no ARexx or UI dependency is introduced into the protocol/session core

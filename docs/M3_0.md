# M3.0 — ARexx foundation

M3.0 establishes the command contract and public-port lifecycle for RexxTelnet.

## Public port

The application publishes the ARexx port:

`REXXTELNET`

Only one instance may own that public port at a time.

## RC contract

- `0` success
- `5` warning / state-related refusal
- `10` syntax, command, or execution error

Commands should return useful text in `RESULT` whenever practical.

## Initial command vocabulary

- `STATUS`
- `CONNECT host [port]`
- `DISCONNECT`
- `SEND text`
- `SENDLINE text`
- `GET property`
- `SET property value`
- `QUIT`

M3.0 provides the host-testable command parser and the Amiga public-port lifecycle. Message decoding, command dispatch, replies, and event-loop integration are the next M3 step.
